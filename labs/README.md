# Agendamento SM-2 em Clojure

Funcoes puras para um prototipo de repeticao espacada: nota de recordacao (0..5), intervalo, repeticoes e fator de facilidade.

Teste: clojure -M -e "(load-file \"labs/clojure/scheduler.clj\") (clojure.test/run-tests 'scheduler)"

O codigo e isolado do aplicativo Kotlin existente. Ajuste de parametros depende de validacao pedagogica.
